# تطبيق محمد سلومة – وريث الصمت

هذا مشروع Android أولي جاهز للاستيراد في Android Studio.

المحتوى الحالي:
- واجهة رئيسية عربية RTL
- الكتب
- الأبحاث
- خلف الصمت
- لماذا نثق في البشر؟
- موقع الكاتب
- تواصل معنا

رابط الموقع مضاف داخل التطبيق:
https://sites.google.com/view/mohamed-slomah

## طريقة إخراج APK
1. افتح المشروع في Android Studio.
2. انتظر اكتمال Gradle Sync.
3. اختر Build > Build APK(s).
4. ملف APK التجريبي سيظهر داخل app/build/outputs/apk/debug/.

## ملاحظة
هذه نسخة أولى للتجربة، وليست بعدُ نسخة Google Play النهائية. قبل النشر سنضيف أي ملفات كتب فعلية وروابط Facebook/WhatsApp والأيقونة النهائية وبيانات المتجر.
